# Clinical NER Pipeline — East African Epidemiology

A hybrid Named Entity Recognition system that extracts structured epidemiological entities from research abstracts using a combination of rule-based matching and a biomedical transformer model.

## Live Demo
https://clinical-ner-pipeline-pua7w9ovmxrflqtcuungsn.streamlit.app/ 

## What it extracts
- Diseases and conditions
- Study designs
- Populations
- Risk factors
- Locations
- Interventions
- Statistics and time references

## Tech Stack
spaCy · Hugging Face Transformers · d4data/biomedical-ner-all · Streamlit · Python 3.11

## Use Case
Designed to accelerate systematic reviews and meta-analyses of East African health literature. Paste any epidemiological abstract and get structured entity extraction instantly.
